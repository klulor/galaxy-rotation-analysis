# Input data

Download the [SDSS-IV MaNGA DR17 DRP v3_1_1 LOGCUBE for plate-IFU 8244-12704](https://data.sdss.org/sas/dr17/manga/spectro/redux/v3_1_1/8244/stack/manga-8244-12704-LOGCUBE.fits.gz) and place it in this directory as `manga-8244-12704-LOGCUBE.fits.gz`.

The FITS data are excluded from this repository. See the main README for data provenance, analysis assumptions and attribution.

The cube contains 4,563 wavelength samples on a 74 × 74 spatial grid. The analysis uses the `FLUX`, `IVAR`, `MASK` and `WAVE` extensions. See the [MaNGA DR17 data documentation](https://www.sdss4.org/dr17/manga/manga-data/) and [LOGCUBE data model](https://data.sdss.org/datamodel/files/MANGA_SPECTRO_REDUX/DRPVER/PLATE/stack/manga-PLATE-IFU-LOGCUBE.html).
